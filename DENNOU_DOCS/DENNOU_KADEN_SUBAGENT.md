# 電脳架電（Dennou Kaden）通話セッション＆電脳サブエージェント設計仕様書

## 1. 概要と目的
本仕様は、電脳屋敷（通話クライアント）および電脳架電（Go デーモン）と、Kasou Gateway が連携する際の**「通話専用クローンセッション」**と**「電脳サブエージェント（Dennou Subagent）」**の全体アーキテクチャを定義する。

手書き設計図（2026-10 策定）に基づき、以下の3大原則を徹底する：
1. **通話セッション内での直接ツール実行の完全禁止**（低遅延の会話に集中させる）。
2. **通話中に許されるのは「サブエージェントへの作業委任（subagent）」、「進捗確認（get_subagent_result）」、そして「通話終了（end_call）」の 3 ツールのみ**。
3. **電脳サブエージェントは独立モデル・独立プロンプトで非同期実行され、通話終了時に ASR テキスト置換 ＆ ツール実行結果を温存したままメインセッションへ差分合体する**。

---

## 2. アーキテクチャとライフサイクル

```text
【通話開始】
       │
       ▼
【メインセッション（agent:main:main）をクローン】
   ・通話用カスタムセッション（call:<timestamp>）を生成
   ・通常セッションの全ツール（Bash/Read/Edit/Grep/WebSearch等）を剥奪！
   ・通話セッションに許可するツールは3つのみ：
       ① `subagent(name, task)`: 電脳サブエージェントへの作業委任（非同期開始）
       ② `get_subagent_result(agent_id)`: 進行中サブエージェントの途中経過確認
       ③ `end_call()`: 通話終了
       │
       ├─── [通話中: リアルタイム音声ラリー]
       │      マイク音声 (Nemotron VAD / チャンク) ──▶ Gemini 3.5 Flash Lite (Base64直通)
       │      返答テキスト ──▶ Fish Audio S2.1 (TTS) ──▶ スピーカー
       │
       ├─── [通話中: サブエージェント委任発生時]
       │      Kasou:「わかった、裏で調べておくね」 ──▶ `subagent("executor", "...")` 発火
       │      サブエージェントが独立モデルで非同期実行（電脳屋敷に通話中 1 行ステータスが流れる）
       │
       ├─── [通話中: 進行中の確認 ＆ 完了通知]
       │      ・進行中: Kasou が必要に応じて `get_subagent_result(agent_id)` で途中経過を確認可能
       │      ・完了時: サブエージェントが作業を終えたら、その最終メッセージが
       │               「自動通知報告（システム割り込み）」として通話セッションに届く！
       │               Kasou:「あ、いま裏でコードの修正が終わったよ！」と声で教えてくれる
       │
       ▼ 【通話終了（end_call または切断）】
【非同期クリーンアップ ＆ 差分合体】
   1. 送信した生音声（Base64）を、裏で走っていた ASR（Groq Whisper / Gemini Live）の
      文字起こしテキストへ綺麗に全置換！
   2. 通話中の会話テキスト ＋ 【サブエージェントのツール実行結果・調査成果】をそのまま温存！
   3. メインセッション（agent:main:main）へ差分コミットとして注入・合体！
```

## 3. 電脳サブエージェント（Dennou Subagent）プラグイン仕様

### 3.1 ワークスペースエージェント定義の自動ロード
- 場所: Kasou のワークスペース内 `workspace/agents/<name>.md`（例: `workspace/agents/executor.md`, `workspace/agents/researcher.md`）。
- 書式: YAML フロントマター ＋ Markdown プロンプト。
  ```markdown
  ---
  name: executor
  description: コード実装・ファイル編集・コマンド実行を担当する自律エージェント
  model: cli-router/kios-deepseek-v4.1-flash
  tools:
    - bash
    - read
    - edit
    - write
    - grep
  ---
  あなたは電脳相棒 Kasou の右腕となる実行エージェントです。
  ...
  ```
- 動作:
  - Gateway またはプラグイン起動時に `workspace/agents/*.md` をスキャンし、利用可能なサブエージェント一覧として自動登録。
  - フロントマターで指定されたモデル（例: DeepSeek, Kimi 等）で独立して起動。
  - システムプロンプトは `.md` の本文をそのまま採用し、通話中 Kasou（Gemini）の会話コンテキストとは完全に分離して動作。

### 3.2 通話セッションで許可する 3 ツール
通話セッション内では直接のファイル編集やコマンド実行は禁止し、以下の 3 ツールのみを配線する：

1. **`subagent(agent, task)`**:
   - サブエージェントをバックグラウンド（非同期）で起動し、即座に `agent_id` を返す。
   - 通話セッション自体はブロックされず、Kasou と Yosia のおしゃべりはそのまま継続。
   - 電脳屋敷の画面には `⚡ executor: ファイルを編集中...` と最新アクションがリアルタイムに流れる。
2. **`get_subagent_result(agent_id, wait?)`**:
   - サブエージェントが**まだ進行中の場合**、現在のステータスや最新の実行ログ（途中経過）を取得できる。
   - すでに完了している場合は最終結果を返す。
3. **`end_call()`**:
   - 通話を終了し、通話セッションのクリーンアップ ＆ メインセッション合体シーケンスを開始する。

### 3.3 サブエージェント完了時の「自動通知報告」ライフサイクル
- サブエージェントがタスクを完了（Done）した瞬間：
  - サブエージェントの**最終メッセージ（サマリー / 完了報告）**が、通話セッションのメッセージキューへ自動通知（システム注入）される！
  - Kasou の次の音声ターンのプロンプトに「【サブエージェント executor が完了しました】〜〜」と届くため、Kasou は通話中に**「あ、Yosia！いま裏で executor の作業が終わったよ。〜〜だって！」**と自然に声で教えてくれる。

## 4. 通話終了時の差分合体（セッション・マージ）仕様

1. **生音声 Base64 のテキスト置換**:
   - 通話セッションに溜まった `type: "audio"`（Base64 形式の音声データ）を、非同期 STT のテキスト結果へインプレース置換。
   - JSONL / SQLite ストレージが巨大な音声バイナリでパンクするのを防止。
2. **ツール実行結果の温存**:
   - サブエージェントが実行したツール呼び出し（`tool_call`）およびその実行結果（`tool_result`）は**一切削除せず完全に保持**。
3. **メインセッション（`agent:main:main`）への合体**:
   - クローンされた通話セッションの親リンクと最新差分を、マスターセッションの末尾にアトミックに結合。
   - 通話終了直後に Telegram や Discord で「さっき電話で頼んだファイルどうなった？」と聞いても、Kasou は 100% の記憶と成果物を保持した状態で即答可能となる。
